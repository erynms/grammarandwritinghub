# Images Directory

This folder contains images used throughout Professor Shorthill's Grammar and Academic Writing Skills Hub.

## Required Images

- **EFSCLogo_Library.jpg** - EFSC Library logo used for the Research Guides button
  - This file should be placed in this directory
  - Recommended dimensions: 300-600px wide
  - Format: JPG

## Adding Images

To add the library logo:
1. Place `EFSCLogo_Library.jpg` in this directory
2. The image will automatically appear on the Browse Topics and Ask a Question pages
3. It links to: https://libguides.easternflorida.edu/
